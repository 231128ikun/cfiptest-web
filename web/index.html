使用说明

① 测速工作台

三步流水线：准备候选（粘贴 / 文件 / 远程 URL / 官方段，或「从本地库导入」）→ 检测规则（延迟、测速、数量）→ 检测及结果（筛选、排序、自定义展示）。结果可复制、下载，或按导出范围（全部 / 当前规则 / 自定义）导入到指定 IP 库。

整体约束：达到数量即停止检测；只测延迟按延迟合格数计数，继续测速按同时满足延迟与速度条件的数量计数；清空结果后可继续检测。

结果范围筛选：填「100~500」为区间；延迟只填一个数为上限（小于该值），速度只填一个数为下限（大于该值）。

官方 IP 模式：IPv4 按每个 /24 抽样，避免直接检测百万级地址；可选择 Cloudflare 支持的 HTTP/HTTPS 端口。

② 自动维护

新建任务 → 绑定 IP 库，设规则：字段（国家/城市/端口）多值=或、多字段=交集，每个组合取前 N 条；延迟/速度范围（测速总开关开启后可用）；总数限制。保存并勾选「启用」后，点顶部「一键维护」依次执行；输出按模板写入 data/out/（输出文件名留空时使用独立默认路径，不会覆盖初始化文件）。

维护来源：本地库检测后会回写状态（失效移除、测速失败保留）；官方 IP 段与远程 URL 只作为本次候选，不写回、不删除来源。系统会持续检测，直到规则配额满足或候选耗尽。

③ IP 库

多个命名库（data/ipdb/），可新建/改名/删除/清空。库内条目随检测自动更新：延迟失败移除、测速失败保留、结果回写。

④ 运行记录

每次维护的摘要与明细（data/runs.jsonl），可追溯。

⑤ 设置

全局默认检测参数、数据源与颜色阈值（data/config.json、data/settings.json）。

自动维护默认值：延迟对每个 IP 独立探测多次并对成功结果取平均，HTTP 校验 1 次、单请求超时默认 3 秒；连续失败达到阈值（默认 3 次）才从库移除，达到阈值前保留并累计。并发过高可能造成漏测或误判，建议从延迟 50 / 测速 5 开始，再按机器和网络逐步调整。

结果颜色阈值：输入框编辑所在区间的右端值，其余区间会自动衔接；未测速显示灰色。

提示：本程序为本地单机应用，双击 exe 即启动服务。重复启动时会自动打开已运行的实例，不会重复占用端口；需要退出时点击右上角红色电源按钮，再点「确认退出」，或关闭黑色控制台窗口。

退出程序

确认要退出吗？退出后服务将停止，需要重新启动才能继续使用。
